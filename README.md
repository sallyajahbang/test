# Glues

Aplikasi Android untuk membuat video sebagai live wallpaper.

- Jetpack Compose + Material 3 (AndroidX)
- Browser video dengan preview dan thumbnail
- Mute, skala (0.5x - 3x) sesuai layar, dan geser posisi video
- Render memakai OpenGL ES (SurfaceTexture) agar ringan
- Build otomatis lewat GitHub Actions (`.github/workflows/build.yml`)
